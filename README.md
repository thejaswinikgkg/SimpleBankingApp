# AmisPay – User-Centric Mobile Banking Application

## Project Overview
AmisPay is a simplified mobile banking application prototype
developed as an academic project to demonstrate basic digital
banking operations.

This is a demo application and does not perform real banking,
UPI, or financial transactions.

## Features
- Customer verification
- OTP-based registration
- Password and secret-key setup
- Secure login using JWT
- Account dashboard
- Balance checking
- Transaction history
- Money transfer simulation
- Change password
- QR code for account identification
- Logout

## Demo Bank
A separate Demo Bank module is included to create simulated
customers and accounts for testing AmisPay.
